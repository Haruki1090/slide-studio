# 物語設計とヘッドメッセージ

F2 / F3 に入る直前に読む。

## 1. ガバニングソート

資料全体が主張することを **1 文**に畳む。主語と述語を持ち、80 字以内。
これが決まらないとスライドは並列の情報の束になる。

良い例：

> 代アニは「専門校」から「自社 IP を持つエンタメ事業会社」へ転換した。教育事業が縮小市場である一方、アイドル事業が収益・集客・カリキュラムの三役を担う構造になっている。

悪い例：

> 代アニの事業構造とアイドル事業の動向について（← 主張が無い。題目でしかない）

**1 文が書けたら、各枚がそれを支持する論証になっているか逆算で確かめる。**
支持していない枚は落とす。落とせないなら 1 文のほうが間違っている。

## 2. 構成型（4 つ）

物語が立たないときは、無理に成長ストーリーを作らず**型を替える**。

| 型 | 使う条件 | 骨子の骨格 |
|---|---|---|
| **推移型** | 時系列で明確な変化がある | 現在地 → 何が変わったか → どれだけ → なぜ → 何を生むか → 論点 → 今後 |
| **比較型** | 複数の対象が同じ軸で並ぶ | 比較の軸の定義 → 各対象 → 差がどこから来るか → 含意 |
| **分解型** | 全体を構成要素に割れる | 全体像 → 分解 → 各要素の寄与 → 効くのはどれか → 打ち手 |
| **論点整理型** | 事実は集まるが方向が定まらない | 前提の整理 → 争点 → 各論の根拠 → 判断に必要な情報 → 未決事項 |

**論点整理型は逃げではない。**方向が定まらない題材で推移型を装うと、
根拠のない断定が混ざる。定まらないことを構造にするほうが誠実で、読み手にも使える。

## 3. 標準の骨格（推移型・13 枚）

枚数が可変なので目安。材料が薄ければ削る。

```
01 表紙
02 エグゼクティブサマリー（発見を 3〜4 個）
03 対象の基礎情報（ファクトシート）
04 何が変わったか（構造の Before / After）
05 定量の裏づけ（業績・規模）
06 対象の全体像（ポートフォリオ・構成要素）
07 中核の伸び（推移①）
08 中核の伸び（推移②・別の指標）
09 なぜ伸びたか（構造の転換）
10 それが何を生むか（波及・循環）
11 外部環境（追い風と向かい風の対比）
12 論点とリスク
13 今後の注目点（タイムライン）
```

02 は最後に書く。先に書くと本編と食い違う。

## 4. ヘッドメッセージの規約

**ボディを先に固めてから書く。**逆順にすると結論がボディから出てこない。

- **述語を持つ文にする。**体言止めは禁止（`check_layout.py` が警告を出す）
- タイトルとは役割が違う。タイトル＝領域名、ヘッドメッセージ＝その領域から言えること
- 1 枚 1 メッセージ。2 文以上になったら分割を検討する
- 1 行あたりの全角換算上限を超えたら、フォントを縮めるのではなく**論点を分割する**

| タイトル | 悪い（体言止め） | 良い（結論） |
|---|---|---|
| 業績推移 | 業績の推移 | 当期純利益は FY2026/3 に 9.2 億円と過去最高 |
| 外部環境 | 市場と人口動態 | 向かう市場は拡大、依存する人口は縮小しており、見通しは逆方向にある |
| 論点 | 主要なリスク | 最大の論点は単一プロデューサーへの依存と、収益指標の再設計である |

書き終えたら、**ヘッドメッセージだけを上から拾い読みする。**
それだけで筋が通らないなら、順序か分割が間違っている。

## 5. 枚数の判断

| 材料の量 | 対応 |
|---|---|
| 論証に 6 枚も要らない | **スライドではなく短い文書を提案する** |
| 6〜20 枚に収まる | そのまま |
| 20 枚を超える | 本編を 12〜15 枚に絞り、残りを Appendix へ。本編は結論に必要なものだけ |

**足りないときに一般論・定義・「〇〇とは」で埋めない。**
枚数を減らして、減らした理由を伝えるほうが価値が高い。
